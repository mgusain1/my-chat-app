# Real-Time Chat Application

A full-stack real-time chat application built with React, Firebase, and Chat Engine.

## Features
- Real-time messaging with instant delivery
- User authentication via Firebase (sign up, login, logout)
- Multiple chat rooms support
- Clean, responsive UI built with React

## Tech Stack
- **Frontend:** React, JavaScript
- **Authentication:** Firebase Auth
- **Real-time Backend:** Chat Engine API
- **Bootstrapped with:** Create React App

## Getting Started
1. Clone the repo
2. Run `npm install`
3. Add your Chat Engine and Firebase credentials to `.env.local`
4. Run `npm start`
